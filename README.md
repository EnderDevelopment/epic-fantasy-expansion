# EpicFantasyExpansion

EpicFantasyExpansion is a comprehensive Minecraft plugin that transforms your world into a vast, immersive fantasy realm. This plugin introduces 100 unique fantasy creatures, 30 enormous structures, 20 new biomes, 15 exploration regions, 50 quests, 25 puzzles, and 10 enormous fantasy guardians. It also includes new magical transportation systems, collectible artifacts, secret locations, custom animations, environmental storytelling, exploration achievements, and a complete progression system. Everything is designed to work seamlessly in survival and multiplayer modes, ensuring a rich and engaging experience for all players.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/EnderDevelopment/EpicFantasyExpansion/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Start your Minecraft server with the plugin installed.
2. Join your Minecraft world and explore the new biomes and regions.
3. Interact with the new creatures, structures, and objects to progress through the quests and puzzles.
4. Use the magical transportation systems to travel between different locations.
5. Collect artifacts and complete achievements to unlock new content and progress through the game.
